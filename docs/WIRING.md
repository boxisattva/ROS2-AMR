## 3. Подключение TB6612FNG (драйвер моторов)

### 3.1 Распиновка TB6612FNG
                TB6612FNG (Dual H-Bridge)
                ┌─────────────────────────┐
                │  VM  ┃  VCC  ┃  GND  ┃  GND  │
                │  6-9V┃ 3.3V  ┃  GND  ┃  GND  │
                ├─────────────────────────┤
                │  A01 ┃  A02  ┃  B02  ┃  B01  │
                │  M1+ ┃  M1-  ┃  M2-  ┃  M2+  │
                ├─────────────────────────┤
                │  PWMA┃  AIN2 ┃  AIN1 ┃  STBY │
                │  PWM1┃  DIR1-┃  DIR1+┃  ON/OFF│
                ├─────────────────────────┤
                │  PWMB┃  BIN2 ┃  BIN1 ┃       │
                │  PWM2┃  DIR2-┃  DIR2+┃       │
                └─────────────────────────┘
                
VM  → Батареи 6V (4× AA)
VCC → ESP32 3.3V (логика!)
GND → Общий GND (ESP32 + батареи)

A01/A02 → Левый TT-мотор
B01/B02 → Правый TT-мотор

## 4. Подключение периферии

### 4.1 WS2812B LED-лента
ESP32          WS2812B (1 м, 30 диодов)
┌─────────┐    ┌─────────┐
│  5V ────┼────┼──→ +5V  │  (питание от USB ноутбука)
│  GND ───┼────┼──→ GND   │
│  GPIO21 ┼────┼──→ DIN   │  (данные, 800 кГц)
└─────────┘    └─────────┘

⚠️ Ток: 30 диодов × 60 мА (белый) = 1.8A максимум!
   Реально: 300 мА при зелёном/красном.
   USB ноутбука выдаёт 500 мА — достаточно.


### 4.2 Buzzer (активный 5V)
ESP32          Buzzer
┌─────────┐    ┌─────────┐
│  GPIO22 ┼────┼──→ (+)   │
│  GND ───┼────┼──→ (-)   │
└─────────┘    └─────────┘

Ток: < 20 мА. Можно напрямую от GPIO.
Если пассивный buzzer — нужен PWM (GPIO22 = PWM).


### 4.3 CP2102 (USB-UART мост)
Ноутбук        CP2102          ESP32
┌─────────┐    ┌─────────┐    ┌─────────┐
│ USB-A   ┼────┼──→ USB   │    │         │
└─────────┘    │  TXD ───┼────┼──→ RX0   │  (GPIO3, RX)
               │  RXD ───┼────┼──→ TX0   │  (GPIO1, TX)
               │  GND ───┼────┼──→ GND   │
               │  3.3V ──┼────┼──→ 3.3V  │  (опционально, ESP32 питается от USB)
               └─────────┘    └─────────┘
               
⚠️ Важно: GND CP2102 ↔ GND ESP32 ↔ GND батарей = ОБЩИЕ!

## 5. Безопасность и защита от КЗ

### 5.1 Распределение токов

| Компонент | Напряжение | Типичный ток | Максимальный ток | Примечание |
|-----------|-----------|-------------|------------------|------------|
| ESP32 | 5V (USB) | 80 мА | 240 мА | Wi-Fi включён |
| TB6612FNG (логика) | 3.3V | 1 мА | 5 мА | VCC пин |
| TB6612FNG (силовая) | 6V | 200 мА | 1.2A | VM пин, моторы в стопе / в движении |
| WS2812B (30 LED) | 5V | 100 мА | 1.8A | Зависит от цвета и яркости |
| Buzzer | 3.3V | 10 мА | 20 мА | — |

### 5.2 Правила безопасности
┌─────────────────────────────────────────────────────────────────┐

│     ─────────────                                               │

│     должны быть соединены. Иначе UART даст сбои, моторы могут    │
│     работать нестабильно.                                       │
│                                                                 │
│  3. РАЗДЕЛЕНИЕ ПИТАНИЯ                                          │

│     • Логика: 3.3V / 5V от USB ноутбука (низкий ток, безопасно)│

### 5.3 Что делать при дыме / запахе гари

| Симптом | Вероятная причина | Действие |
|---------|-------------------|----------|
| Дым от TB6612FNG | Переполюсовка VM/VCC, КЗ моторов | Немедленно отключить батареи. Проверить полярность. Заменить драйвер (~624 ₽) |
| Греется ESP32 | Короткое замыкание на GPIO | Отключить USB. Проверить Dupont-провода на GND ↔ 3.3V |
| Моторы не крутятся | STBY = LOW, нет PWM, обрыв | Проверить GPIO19 (STBY), GPIO2/17 (PWM), мультиметром прозвонить |
| LED не горит | Нет 5V, неправильный DIN | Проверить USB-питание, GPIO21 |
