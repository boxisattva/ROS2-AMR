## 2. Карта GPIO ESP32-DevKitC V4 (Week 3)

### 2.1 Таблица распиновки

| GPIO ESP32 | Направление | Компонент | Пин | Функция |
|------------|-------------|-----------|-----|---------|
| **GPIO 21** | OUT | WEMOS Shield | D2 | SDA (I2C) |
| **GPIO 22** | OUT | WEMOS Shield | D1 | SCL (I2C) |
| **GPIO 4** | IN_PULLUP | Кнопка | — | E-Stop (LOW = нажата) |
| **GPIO 25** | OUT | LED1 | Анод | Статус: Ready |
| **GPIO 26** | OUT | LED2 | Анод | Статус: E-Stop |
| **GPIO 32** | OUT | LED3 | Анод | Статус: Watchdog |
| **GPIO 33** | OUT | LED4 | Анод | Статус: Motion |

### 2.2 Примечание
- **USB-UART:** onboard CP2102 на DevKitC V4. Внешний CP2102-модуль **не используется**.
- **LED:** 4 красных диода с токоограничивающими резисторами 220 Ω. Без резисторов GPIO перегрузится.
- **E-Stop:** `INPUT_PULLUP` на GPIO4, внешний резистор не нужен.

               

## 3. WEMOS Motor Shield v1.0

### 3.1 Распиновка WEMOS Motor Shield

| Shield | Подключение |
|--------|-------------|
| VM | Батареи 4×AA (6V) |
| GND | GND ESP32 + GND батарей |
| A1, A2 | Левый TT-мотор |
| B1, B2 | Правый TT-мотор |
| SDA (D2) | GPIO21 ESP32 |
| SCL (D1) | GPIO22 ESP32 |


### 3.2 Обновлённая схема подключения

БАТАРЕИ (6V)                    
┌─────────┐                     
│  + ─────┼─────→ VM (TB6612)   
│  - ─────┼─────→ GND (TB6612)  
└─────────┘                     

WEMOS Motor Shield
┌─────────┐
│  A01 ───┼──→ Левый мотор (+)
│  A02 ───┼──→ Левый мотор (-)
│  B01 ───┼──→ Правый мотор (+)
│  B02 ───┼──→ Правый мотор (-)
└─────────┘

⚠️ Общий GND: ESP32 ↔ WEMOS Motor Shield ↔ батареи — обязательно соединить!
⚠️ Конденсаторы 100нФ параллельно клеммам каждого мотора — подавляют щеточный шум.

## 5. Безопасность и защита от КЗ

### 5.1 Распределение токов

| Компонент | Напряжение | Типичный ток | Максимальный ток | Примечание |
|-----------|-----------|-------------|------------------|------------|
| ESP32 | 5V (USB) | 80 мА | 240 мА | Wi-Fi включён |
| TB6612FNG (логика) | 3.3V | 1 мА | 5 мА | VCC пин |
| TB6612FNG (силовая) | 6V | 200 мА | 1.2A | VM пин, моторы в стопе / в движении |
| WS2812B (30 LED) | 5V | 100 мА | 1.8A | Зависит от цвета и яркости |
| Buzzer | 3.3V | 10 мА | 20 мА | — |

### 5.2 Правила безопасности
┌─────────────────────────────────────────────────────────────────┐
│  ⚠️ ОБЯЗАТЕЛЬНО К ПРОЧТЕНИЮ ПЕРЕД ВКЛЮЧЕНИЕМ                   │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  1. ПОЛЯРНОСТЬ БАТАРЕЙ                                          │
│     ─────────────────                                           │
│     Перепутать + и - на TB6612FNG = мгновенное уничтожение      │
│     драйвера. Проверьте мультиметром перед первым включением.   │
│                                                                 │
│  2. ОБЩИЙ GND                                                   │
│     ─────────────                                               │
│     GND ноутбука, GND ESP32, GND батарей, GND TB6612FNG —     │
│     должны быть соединены. Иначе UART даст сбои, моторы могут    │
│     работать нестабильно.                                       │
│                                                                 │
│  3. РАЗДЕЛЕНИЕ ПИТАНИЯ                                          │
│     ───────────────────                                         │
│     • Логика: 3.3V / 5V от USB ноутбука (низкий ток, безопасно)│
│     • Двигатели: 6V от батарей (высокий ток, отдельный контур) │
│     НЕ подключайте моторы к 5V USB — перегрузите порт ноутбука! │
│                                                                 │
│  4. ЗАЩИТА ОТ КЗ                                                │
│     ─────────────                                               │
│     • Диод Шоттки параллельно моторам (опционально, ~50 ₽)      │
│     • Конденсатор 100 мФ на VM близко к TB6612FNG               │
│     • Если мотор «заедает» — ток резко растёт, драйвер греется │
│       → немедленно выключить, проверить механику                │
│                                                                 │
│  5. ПРОВЕРКА ПЕРЕД ПЕРВЫМ ПУСКОМ                                │
│     ───────────────────────────                                 │
│     [ ] Мультиметр: VM = 6V, VCC = 3.3V                         │
│     [ ] Мультиметр: GND общий на всех модулях                   │
│     [ ] Визуально: нет перекрученных/голых проводов            │
│     [ ] ESP32 прошит тестовой программой (мигает LED)           │
│     [ ] Батареи отключены, проверяем логику (USB только)        │
│     [ ] Батареи подключены, проверяем моторы (короткий тест)    │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘


### 5.3 Что делать при дыме / запахе гари

| Симптом | Вероятная причина | Действие |
|---------|-------------------|----------|
| Дым от TB6612FNG | Переполюсовка VM/VCC, КЗ моторов | Немедленно отключить батареи. Проверить полярность. Заменить драйвер (~624 ₽) |
| Греется ESP32 | Короткое замыкание на GPIO | Отключить USB. Проверить Dupont-провода на GND ↔ 3.3V |
| Моторы не крутятся | STBY = LOW, нет PWM, обрыв | Проверить GPIO19 (STBY), GPIO2/17 (PWM), мультиметром прозвонить |
| LED не горит | Нет 5V, неправильный DIN | Проверить USB-питание, GPIO21 |
